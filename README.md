# Relatório de Concorrentes — SaaS de Atendimento Humanizado para Clínicas

Este repositório contém a análise de concorrentes (benchmarking) e a geração de tabelas e gráficos via Jupyter Notebook para embasar uma apresentação.

## Estrutura
- `data/` — arquivos CSV com dados dos concorrentes
- `notebook/` — notebooks Jupyter para análise e gráficos
- `outputs/` — tabelas e gráficos gerados

## Como rodar
1. Crie um ambiente virtual (opcional)
2. Instale dependências (ver `requirements.txt`)
3. Rode o notebook em `notebook/relatorio.ipynb`
